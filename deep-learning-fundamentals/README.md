## Notes

- Each file concatenates that chapter's Python blocks in document order, separated by `# --- block N ---` markers.
- Non-Python blocks (shell commands, sample output, JSON, plain text) are not included.
- Blocks are teaching excerpts. Many assume variables or imports introduced earlier in the chapter or in an earlier chapter, so an individual file is not guaranteed to run standalone.
- The only code the generator writes itself is the `# --- imports (added by the generator) ---` block: a canonical import line for a well-known alias (`np`, `torch`, `nn`, ...) that the chapter uses as a module but never imports and never assigns. Nothing else is added, and no book code is rewritten.
- A block tagged `python` in the book that will not compile - prose, pseudo-code, or a fragment shown out of context - is kept verbatim but commented out, labelled `# --- block N (DOES NOT COMPILE - COMMENTED OUT) ---`.

## Runnability pass

Every `.py` file here compiles (`python3 -m py_compile`) and resolves every name it uses (`python3 -m pyflakes`, zero "undefined name" findings). Four kinds of repair were applied, all of them additive - no book code was rewritten or deleted:

- **`context.py`** - a shared module, not part of the book, holding the classes and objects a later chapter reuses from an earlier one (`Dense`, `ReLU`, `SoftmaxCrossEntropy`, the `dense1 -> relu -> dense2` network, the batch `X`/`y`, `Optimizer_SGD`). Every definition in it is copied verbatim from the book, with the source chapter named above it. Chapters 19, 23, 25, 31, 36 and 37 import from it.
- **Hoisted forward references** - where a chapter uses a name in an early block that it only defines in a later block (chapters 8, 11, 17, 23), the book's own later definition is copied verbatim to the top of the file under a `# --- forward reference ---` header.
- **Reader placeholders** - hyper-parameters, datasets and model handles the book deliberately leaves to the reader (chapters 24, 33, 37, 38) are stubbed with an obvious value and a `# TODO` comment. Stubs are honest markers, not implementations.
- **Prose blocks** - blocks tagged `python` that are actually maths notation with no assignable values (chapter 17 block 1, chapter 27 block 1, chapter 31 block 1) are commented out and labelled `# NOTE: this block is prose in the book, not runnable code.`

Two `redefinition of unused` pyflakes findings remain, in chapters 13 and 19. Both are deliberate book pedagogy - the chapter shows a first version of a function, then an improved one - and are left as written.
